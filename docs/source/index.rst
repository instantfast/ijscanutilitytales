IJ Scan Utility: Installation, Scanning and Troubleshooting
==========================================================

IJ Scan Utility is a Canon scanning application used with compatible scanners and multifunction printers. It lets you scan documents and photographs, choose how files are saved, and adjust settings for different scanning tasks.

The application available for your device depends on its model and operating system. Some devices use IJ Scan Utility, while others use IJ Scan Utility Lite or another scanning application.

This guide explains how to prepare your scanner, install compatible software, scan a document, and troubleshoot common connection problems.

What Is Canon IJ Scan Utility?
-------------------------------

Canon IJ Scan Utility provides a way to start scans from your computer. Depending on your device and software version, it may offer options for documents, photographs, automatic scanning, and custom settings.

You can use it to capture paper documents as digital files and save images for later use. Available file formats, document feeder options, and image processing features vary by model.

A printer must include scanning hardware to work as a scanner. Installing the application does not add scanning capability to a single-function printer.

Before You Begin
----------------

Check the exact model name on your scanner or multifunction printer. Then confirm which scanning application is available for that model and your operating system.

Prepare the following:

* A powered-on scanner or multifunction printer.
* A working USB or local network connection.
* Compatible scanner software.
* A document or photograph to scan.
* A destination folder where you can save files.

Resolve any error displayed on the printer before starting. An active device error can prevent scanning even when the application opens normally.

IJ Scan Utility Download and Installation
-----------------------------------------

When looking for an IJ Scan Utility download, choose a trusted software source and check the model and operating system details carefully.

For some devices, the utility is included in a driver package. For others, the scanning application is provided separately.

Avoid packages intended for a different printer or scanner. Similar model names do not guarantee compatibility.

Install on Windows
~~~~~~~~~~~~~~~~~~

Run the compatible installation package and follow its prompts. If you are using USB, connect the cable at the stage requested by the installer.

For a network scanner, confirm that the device is connected to your local network before completing device selection.

After installation, search for IJ Scan Utility from the Windows Start menu. Open the application and check the selected product name.

Install on Mac
~~~~~~~~~~~~~~

Check which application your model uses on macOS. Depending on the device, this may be IJ Scan Utility Lite or another compatible scanning application.

Install the appropriate package, then open the application from its installed location.

Do not assume that a Windows installation package or instructions will apply to your Mac.

IJ Scan Utility for Windows 11 and Windows 10
--------------------------------------------

Before installing IJ Scan Utility for Windows 11 or Windows 10, check that the package is compatible with your scanner model and Windows version.

After installation, open the application and select the intended scanner. If several device entries appear, choose the one matching your current connection.

For wireless scanning, your model's software may include a network scanner selection tool. Use it where required to select the correct device.

Start with a single-page scan before changing advanced settings.

How to Scan a Document with IJ Scan Utility
-------------------------------------------

Position the Document
~~~~~~~~~~~~~~~~~~~~~

Place the document face down on the scanner glass and align it with the positioning mark. Close the lid gently.

If your device has an automatic document feeder, follow its loading diagram. Page orientation and accepted paper types vary by model.

Choose the Scanner
~~~~~~~~~~~~~~~~~~

Open IJ Scan Utility and check the selected product name.

A USB scanner entry and a network scanner entry may appear separately. Choose the entry corresponding to the connection you are using.

Review Scan Settings
~~~~~~~~~~~~~~~~~~~~

Open the settings for your intended scanning task.

Choose the document size, colour mode, resolution, file format, and save location where those options are available.

For ordinary text documents, a moderate resolution usually produces a readable file without making it unnecessarily large.

Start the Scan
~~~~~~~~~~~~~~

Choose the document scanning option and wait for the process to finish. Avoid moving the document or opening the lid during capture.

Open the saved file and check that the page is complete, correctly oriented, and readable.

How to Scan Photos
-------------------

Place the photograph on the scanner glass. Avoid feeding photographs through a document feeder unless your model's instructions explicitly allow it.

Choose the photo scanning option where available and review the colour and resolution settings.

Higher resolution creates larger files and takes longer to process. Choose settings according to whether you want a small digital copy, an enlarged image, or detailed editing.

Keep the original photograph until you have checked the saved image.

Save Scans as PDF
-----------------

Where PDF output is available, select it in the scan settings before starting.

Some configurations allow several pages to be combined into one PDF. You may need to scan additional pages manually or use a compatible document feeder.

Check the page order before saving the final file.

Searchable PDF creation depends on the software's text recognition features and configuration. A scanned PDF is not automatically searchable.

Where Does IJ Scan Utility Save Files?
---------------------------------------

The destination folder depends on your application settings.

Open the settings for the scanning task and check the save location. Choose a folder that is easy to find and that your account can write to.

If saving fails, test a local folder. A disconnected external drive, unavailable network location, or restricted folder can prevent the scan from being saved.

Use clear filenames so that you can identify documents later.

IJ Scan Utility Not Working
---------------------------

If IJ Scan Utility is not working, identify whether the problem happens when opening the application, detecting the scanner, capturing the image, or saving the file.

Application Does Not Open
~~~~~~~~~~~~~~~~~~~~~~~~~

Restart the computer and try again. Check that the installed version is compatible with your device and operating system.

If the installation is incomplete or damaged, reinstall the correct package.

Scanner Is Not Detected
~~~~~~~~~~~~~~~~~~~~~~~

Check that the scanner is powered on and connected.

Confirm the selected product name in the application. Close other scanning programs that may already be using the device.

Scanning Stops Before Completion
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Try scanning one page at a lower resolution. Check the connection and confirm that the document feeder, if used, is not jammed.

If the same problem occurs repeatedly, record the complete error message.

IJ Scan Utility Communication Error
-----------------------------------

A communication error means the application could not complete its exchange with the scanner. The cause may involve the connection, selected device, or another active scanning task.

For USB scanning, reconnect the cable securely and test a direct connection to the computer.

For network scanning, confirm that the computer and scanner are on the same local network. Guest network restrictions or device isolation may prevent communication.

If a VPN or security application restricts local device access, review the relevant settings.

Avoid changing several settings at once. Make one change and try a test scan so you can identify what helped.

Canon IJ Scan Utility Not Finding a Wireless Scanner
----------------------------------------------------

Check the printer's current network name and connection status.

If you recently changed your router or WiFi password, reconnect the printer first. Then select the scanner again in the application or model-specific network selection tool.

Your computer and scanner can use different wireless bands if the router allows them to communicate across the same local network.

A weak signal can interrupt scanning, particularly when transferring large images.

Fix Blank Pages, Lines and Cropped Scans
----------------------------------------

Check which side of the document faces the glass or feeder according to the loading instructions.

Select a scan area or paper size that matches the original. Incorrect settings can crop page edges.

Dust and marks on the glass can create lines or spots. Clean the scanning surface according to the device's care instructions.

Models with a document feeder may also have a narrow scanning glass strip that needs cleaning. Do not spray liquid directly into the device.

Frequently Asked Questions
--------------------------

Is IJ Scan Utility available for every Canon printer?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

No. Availability depends on the model, scanning capability, and operating system. Some devices use a different application.

Can I use IJ Scan Utility without WiFi?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Many compatible devices allow USB scanning. Check your model's connection options and select the correct scanner entry.

Why can my printer print but not scan?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Printing and scanning may use different software components. Check the scanner driver, application, device selection, and connection.

Can IJ Scan Utility scan several pages into one file?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Some configurations allow multipage PDF creation. The process depends on the application version and available scanner features.

Do I need internet access for every scan?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Local USB or network scanning generally does not require an active internet connection once the necessary software is installed. Online destinations and downloads require internet access.

Check Your First Scan
---------------------

Scan one page, open the saved file, and confirm that its contents are clear and complete.

Once the basic process works, adjust the resolution, colour mode, and file format for your usual tasks. Save documents in a consistent location so they are easy to find.
